# Version 0.01

The first public version of this unofficial LineageOS 23.2 / Android 16 build for the Samsung Galaxy Tab A 8.0 (2017), Wi-Fi model SM-T380.

Display, touch, Wi-Fi, brightness, and Settings work. Navigation has been tuned for the tablet's hardware, and charging and suspend work in everyday use.

The download includes the signed OS images, an installer with device and image verification, the matching kernel source, and build instructions. The installer checks the tablet before writing, verifies the installed images, and leaves the data partition in place.

Speaker and microphone support are not included. Camera, Bluetooth, and GApps compatibility are untested. SELinux is enforcing; key storage is software-based and Android Verified Boot is disabled.

Download `lineageos-sm-t380-0.01.zip` with `SHA256SUMS`, then follow the [installation guide](INSTALL.md). The kernel source is included in the kit and available separately as `kernel-source-0.01.tar.gz`.
